# Clinic Appointment System

A Java Web Application developed using NetBeans IDE, JSP, Servlets, JDBC, Apache Tomcat, and MySQL.

## Features
- Book appointments
- View appointments
- MySQL database integration
- Appointment management

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- NetBeans IDE
